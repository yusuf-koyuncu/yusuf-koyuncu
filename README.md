## ⭐ Featured project: [EventTicketing](https://github.com/yusuf-koyuncu/EventTicketing)

A full-stack **event & ticket sales platform** built during my internship: organizers publish events, customers pick seats and buy tickets, and admins track live occupancy and revenue.

- 🔒 **No double booking:** filtered unique index + per-seat row locks + application checks
- 🧱 **Layered ASP.NET Core 10 API** with 25 endpoints, JWT auth and Admin / Organizer / Customer roles
- 🗄 **Code-First SQL Server schema** that separates venue layout, event inventory and pricing
- 🅰️ **Angular client** with an interactive seat map and an occupancy dashboard
